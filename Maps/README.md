This folder contains maps I created across several courses, including some from group projects.
1. DanishAgricultural.png — Final group project for Spatial and Temporal Analysis of Environmental Sciences. We used IPCC scenarios of temperature and precipitation data to predict which crops would be suitable for Denmark in the future.
2. IberianIbex.pdf — Group assignment for Geo-information Tools. We identified the optimal migration route for ibex.
3. NOxExtraChallenge.pdf — Extra assignment for Geo-information Tools. I calculated the change in nitrogen deposition along highways in the Veluwe nature area to assess how a speed limit change could affect this process.
4. SeaGrassMonitoringWaddenSea.pdf — Final assignment for Introduction to GIS. I examined how seagrass distribution coincides with eutrophicated areas in the German Wadden Sea.
